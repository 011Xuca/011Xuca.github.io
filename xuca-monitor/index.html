Qué hace

Dos monitores en una app

Cada pestaña se prende o se apaga. Apagada no gasta nada.

Cortes de internet

Te dice si fue la placa de red (cable o WiFi), el router o tu proveedor, con los eventos de Windows de ese momento.

Lag

Cuando el ping sube y se queda alto, revisa el router, cuánto está bajando la PC, qué programas usan internet y si algún driver pierde memoria.

USB que se desconectan

Cuando suena el ruido de Windows, te dice qué aparato fue (mouse, teclado, auriculares, monitor, Bluetooth...) y si volvió solo.

Junto al optimizador

Te muestra qué opciones de red del Xuca OPtimizer tenés aplicadas, así sabés si alguna tiene que ver.

Liviana

Sin instalar y sin PowerShell de fondo. La ventana solo existe mientras está abierta, y el de USB solo se despierta cuando Windows avisa un cambio.

Todo queda guardado

El registro y el historial quedan en Documentos\Xuca Monitor. La ventana nunca se abre sola: lo mirás cuando quieras.

Cómo se usa

Tres pasos

Abrilo

No se instala. Queda en la bandeja, al lado del reloj.

Marcá Iniciar con Windows

Así arranca escondida cada vez que prendés la PC.

Mirá qué pasó

Cuando algo se corte, abrila desde la bandeja y vas a ver qué fue y qué probar.

Descargar

Un archivo y listo

Para Windows 10 y 11. Usa el .NET que ya trae Windows.

Descargar XucaMonitor.exe Leer la guía

La primera vez Windows puede mostrar un cartel azul (SmartScreen) porque el archivo no está firmado. Tocá Más información y después Ejecutar de todas formas.

Para cerrarla del todo: clic derecho en el ícono de la bandeja > Salir.
