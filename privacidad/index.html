Política de privacidad

Última actualización: noviembre de 2026.

Qué datos guardo: ninguno de mi lado. Este sitio no tiene cuentas, formularios ni base de datos. Solo guarda en tu navegador tus preferencias de tema e idioma.

Publicidad: el sitio muestra anuncios de Google AdSense. Google y sus socios pueden usar cookies para mostrar anuncios según tus visitas a este y otros sitios. Podés ver y desactivar la personalización en adssettings.google.com y leer cómo usa Google los datos en policies.google.com.

Analítica (solo si aceptás): si aceptás el aviso, el sitio carga Google Analytics / Tag Manager (política), Microsoft Clarity, que graba sesiones anonimizadas (política), y Meta Pixel (política). Pueden usar cookies y recibir tu IP y datos de navegación. Si rechazás, ninguno carga. Podés cambiar de opinión borrando los datos de este sitio en tu navegador.

Servicios externos: las páginas consultan la API pública de GitHub para mostrar estrellas, descargas y configs, y cargan tipografías de Google Fonts. Esos servicios reciben tu dirección IP al responder.

Las apps: las apps que se publican en este sitio son gratuitas y de código abierto; no envían datos de tu PC a ningún servidor mío.
